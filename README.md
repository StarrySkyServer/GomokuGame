# Gomoku

Nukkit-MOT 服务端的五子棋插件：自定义方块棋盘 + 实体棋子，支持双人对战。

## 特性

- 2×2 自定义方块拼合的棋盘，资源包随插件打包，客户端无需手动安装
- 棋子为实体，按三进制编码同步棋局状态
- 棋局状态持久化到 `plugins/Gomoku/boards.txt`，服务器重启后自动恢复
- 落点高亮、离开范围自动退出、OP 可收起棋盘

## 安装

1. 从 Release 下载 `Gomoku-1.0.0.jar`
2. 放入服务器 `plugins/` 目录
3. 重启服务器

资源包由 Nukkit-MOT 从插件 jar 内自动下发给客户端；插件更新后资源包版本号会变化，客户端会自动重新下载。

## 使用方法

### 1. 获取棋盘

OP 输入 `/gomoku`，获得「五子棋棋盘」物品。

### 2. 放置棋盘

手持棋盘物品，对着地面右键。需要 2×2 的空地，放置后会消耗 1 个棋盘物品。

### 3. 打开菜单

右键已放置的棋盘。

### 4. 入座

- 无人入座：可选「选择执白方」/「选择执黑方」
- 已有一人入座：显示「加入执白方」/「加入执黑方」
- 座位满 2 人后，其他人无法加入

### 5. 开始棋局

两名玩家入座后，先加入者会看到以下选项：

- 开始棋局（随机先手）
- 开始棋局（对方先手）
- 开始棋局（我方先手）
- 开始棋局（继承棋局）

### 6. 落子

对局进行中，轮到你时瞄准棋盘上的交叉点右键落子，准星处会显示落点高亮。

### 7. 退出棋局

- 菜单点「退出棋局」
- 或离开棋盘中心 7 格范围，会自动退出并结束当前棋局
- 玩家退出游戏也会自动离座

### 8. 收起棋盘

仅 OP 可用：右键棋盘 → 菜单点「收起棋盘」，棋盘会被移除，并把棋盘物品返还给玩家。

> 棋盘方块无法被破坏，收起请走菜单。

## 权限

| 权限 | 说明 | 默认 |
| --- | --- | --- |
| `gomoku.command` | 允许使用 `/gomoku` 获取棋盘 | OP |
