# TabletopGame

Nukkit-MOT 服务端的五子棋插件：自定义方块拼合的棋盘 + 实体棋子渲染，支持双人对战、三档机器人、Swap2 规则与赌博模式。

资源包随插件打包，由服务端自动下发给客户端，无需手动安装。

## 功能特性

- **两种棋盘**：标准 2×2 与大号 4×4，均由自定义方块拼合，棋子为展示实体
- **资源包内置**：客户端自动下载，插件更新后版本号变化会自动重下
- **状态同步**：棋盘 15×15 的落子状态按「棋色槽位」打包写入实体属性（226 槽 / 76 个属性），一次批量同步
- **持久化**：棋局与棋盘状态保存到 `plugins/TabletopGame/boards.txt`，服务器重启后自动恢复
- **配置热重载**：基于 `eu.okaeri.configs`，`/tabletopgame reload` 即可生效
- **摆放朝向**：放置时按玩家视角确定棋盘朝向（南/西/北/东）
- **落点高亮**：准星指向的交叉点实时高亮，离开范围自动退出棋局
- **三档机器人**：入门 / 进阶 / 大师，异步计算不阻塞主线程
- **两种规则**：休闲模式、Swap2（开局摆子 + 交换）
- **赌博模式**：玩家对玩家可下注，赢家获得奖池扣除官方抽水后的奖金（依赖 EconomyAPI）

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 服务端 | Nukkit-MOT |
| Java | 17+ |
| 经济插件 | **EconomyAPI（强依赖）** |

> 本插件在 `plugin.yml` 中以 `depend: [EconomyAPI]` 声明强依赖。未安装 EconomyAPI 时，Nukkit 会直接拒绝加载本插件，不会以「赌博不可用」的降级形态运行。

## 安装

1. 构建或下载 `TabletopGame-1.0.0-SNAPSHOT.jar`
2. 将 jar 放入服务器 `plugins/` 目录
3. 确保已安装 `EconomyAPI`
4. 重启服务器

## 命令与权限

| 命令 | 说明 |
| --- | --- |
| `/tabletopgame` | 获得标准（2×2）棋盘物品 |
| `/tabletopgame 4x4` | 获得大号（4×4）棋盘物品 |
| `/tabletopgame reload` | 重载配置文件（OP 或控制台） |

| 权限 | 说明 | 默认 |
| --- | --- | --- |
| `tabletopgame.command` | 使用 `/tabletopgame`（发放棋盘 / 重载配置） | OP |

## 玩法说明

### 获取与放置棋盘

OP 使用命令获得棋盘物品后，手持对准地面右键放置：

- 放置需要对应的空地（2×2 或 4×4），空间不足或与已有棋盘重叠时会提示
- 棋盘朝向由放置时的视角决定，取最近的 90°：**0=南、1=西、2=北、3=东**；区域从放置点沿玩家左手边与正前方延伸
- 生存模式放置消耗 1 个物品，创造模式不消耗；棋盘物品堆叠上限为 1

### 打开菜单与入座

右键已放置的棋盘打开菜单。菜单内容随座位状态动态变化：

- **0 人入座**：选择执白 / 选择执黑；三个等级的单人对战；更改规则、赌博开关、关于规则
- **1 人入座**：其他人可加入对方棋色；本人可选单人对战或退出
- **2 人入座**：先加入者可选开始棋局，双方均可退出

> 「0 人入座」的菜单是**独占**的：同一时间仅一人可操作，避免两人同时抢座位或改设置。占用者超时（`menuLockSeconds`，默认 30 秒）或下线时会自动释放；点击「关于规则」会立即释放占用。

### 开始棋局

- 两名玩家入座后，由先加入者点击「开始棋局」
- 统一**黑棋先手**
- 上一局已分出胜负/平局后不再提供「继承棋局」，避免重复获胜与重复领奖
- 「开始棋局（继承棋局）」会保留盘面继续对局，先手由盘面棋子数决定

### 落子

对局进行中，轮到你时瞄准棋盘交叉点右键落子，准星处显示落点高亮。落子后会收到提示条（对手落子完成 / 轮到你行棋）。

### 退出与收回棋盘

- 菜单点「退出棋局」
- 或离开棋盘中心一定范围（默认 7 格，可配置）自动退出
- 玩家下线自动离座
- 破坏棋盘任意一块方块即整体收回，并在原地掉落棋盘物品（需自行拾取；创造模式不掉落）。棋盘方块硬度与橡木板一致，斧头挖掘加速

### 规则

在「0 人入座」菜单点击「更改规则」切换，仅 0 人入座且未开局时可改。

**休闲模式**

- 标准五子棋，黑先白后，一人一手
- 任意方向连成 5 子即胜；长连（6 子及以上）同样算胜

**Swap2**

- 「假先手」在盘面任意位置摆 3 子，顺序为黑 → 白 → 黑
- 「假后手」三选一：继续执白 / 交换执黑 / 再落 2 子（先白后黑）
- 若选择再落 2 子，则由「假先手」二选一：继续执黑 / 交换执白
- 开局结束后回归一人一手，由白方落下一子
- 长连（6 子及以上）对双方都不算胜，对局继续
- 角色与选色：选黑者 = 假先手（摆 3 子），选白者 = 假后手（做选择）

### 单人对战

菜单中的「单人对战（入门 / 进阶 / 大师）」可挑战机器人：

- 点击后玩家立即占座（对其他人视为满员），随后选择棋色（含「随机选择」），机器人自动坐到对面
- 机器人落子在异步线程计算，不阻塞服务器主线程；大师档单次思考时间上限 500ms
- 人机对战同样支持 Swap2，摆放阶段机器人按固定棋色顺序落子，选择阶段自行决策
- 战胜机器人可按等级配置奖励（默认不发奖励，见配置文件）

### 赌博模式

仅在**玩家对玩家**对局中生效，由先落座玩家在「0 人入座」菜单开启：

- 开启后隐藏单人对战入口（二者互斥）
- 开局时输入下注金额（需在 `minBet` ~ `maxBet` 之间），双方各扣除该金额，奖池为下注额 × 2
- 获胜方获得「奖池 − 官方抽水」的奖金；平局全额退还
- 中途有玩家退出时，判仍在座的一方获胜并正常结算（不退注）
- 依赖 EconomyAPI，余额不足或扣款失败会给出提示

## 配置文件

首次启动会在 `plugins/TabletopGame/config.yml` 生成配置：

```yaml
# 玩家离开棋盘中心多少格后自动退出棋局（水平方向）
playerRange: 7.0

# 0 人入座时菜单的独占超时（秒）。超时或持有者下线会自动释放占用
menuLockSeconds: 30

# 战胜机器人后的奖励，可配置多项；每项包含 id（物品数字ID）与 count（数量）
rewards:
  # 战胜入门机器人（等级 1）。id=0 且 count=0 表示不发奖励
  beginner:
  - id: 0
    count: 0
  # 战胜进阶机器人（等级 2）。id=0 且 count=0 表示不发奖励
  normal:
  - id: 0
    count: 0
  # 战胜大师机器人（等级 3）。id=0 且 count=0 表示不发奖励
  master:
  - id: 0
    count: 0

# 赌博模式设置（仅玩家对玩家对局生效；本插件强依赖 EconomyAPI）
gambling:
  # 官方每局抽水百分比（0~100，保留两位小数）。默认 1.0 即 1%
  cut: 1.0
  # 每局可下注的最小金额
  minBet: 1000.0
  # 每局可下注的最大金额
  maxBet: 1000000.0
```

说明：

- 每个等级可配置**多个物品**，追加 `- id: xxx` / `count: xxx` 条目即可；奖励发放是静默的
- 修改后执行 `/tabletopgame reload`（OP 或控制台）热重载
- **已生成的 `config.yml` 不会被重载改写**：新增配置项后需手动删除文件重建，或手动补齐字段

## 数据存储

棋盘与棋局状态保存在 `plugins/TabletopGame/boards.txt`，每行一条记录，用 `|` 分隔：

| 行 | 内容 |
| --- | --- |
| `B` | 棋盘头部：世界、坐标、是否进行中、回合、胜者、机器人等级/棋色、棋盘边长、下注金额、赌博开关、规则、Swap2 阶段/已摆子数、朝向 |
| `S` | 座位：玩家 UUID + 棋色 |
| `N` | 玩家名缓存：UUID + 名字（离线时用于显示） |
| `R` | 15 行落子状态的三进制编码 |

启动时由 tick 在关卡加载完成后异步解析并回主线程重建棋盘与棋子实体；保存采用「主线程生成快照 + 单线程异步写盘」，且只重建状态发生变化的棋盘的快照。

## 构建

需要 JDK 17 与 Maven：

```bash
mvn clean package
```

产物：`target/TabletopGame-1.0.0-SNAPSHOT.jar`

## 性能说明

- 机器人搜索、配置解析、存档写盘、读档解析均在异步线程执行，主线程只做状态读取与快照生成
- 棋盘按关卡索引，准星/范围检测只遍历玩家所在关卡
- 落子状态批量同步（一次发包），棋子计数与判满为 O(1)
- 同一 tick 内每人只计算一次高亮；范围比较使用平方距离
- 存档只重建「变脏」棋盘的快照，玩家识别半径等高频配置项以基本类型字段缓存
