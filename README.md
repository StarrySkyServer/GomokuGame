# TabletopGame

Nukkit-MOT 服务端的桌面棋类插件：自定义方块拼合的棋盘 + 实体棋子渲染，内置**五子棋**、**中国象棋 [Beta]** 与**奥赛罗（黑白棋）**三种棋，均支持双人对战、三档机器人、赌博模式。

资源包随插件打包，由服务端自动下发给客户端，无需手动安装。

## 功能特性

- **三种棋**：五子棋（15×15）、中国象棋（9×10 / 32 子）、奥赛罗（8×8 / 64 格）
- **棋盘**：两格标准 2×2 与大号 3×3（五子棋），象棋与奥赛罗均为 2×2，均由自定义方块拼合
- **资源包内置**：客户端自动下载，插件更新后版本号变化会自动重下
- **状态同步**：整盘落子状态按「行」编码进实体整数属性，一次批量同步给客户端
- **单实体渲染**：象棋 32 子 / 奥赛罗 64 格各由**一个**实体绘制，避免海量实体拖垮服务端
- **持久化**：三种棋分别保存到 `plugins/TabletopGame/` 下的存档文件，服务器重启后自动恢复
- **配置热重载**：基于 `eu.okaeri.configs`，`/tabletopgame reload` 即可生效
- **摆放朝向**：放置时按玩家视角确定棋盘朝向（南/西/北/东）
- **落点提示**：准星指向的落点实时高亮，离开范围自动退出棋局
- **三档机器人**：入门 / 进阶 / 大师，异步计算不阻塞主线程
- **赌博模式**：玩家对玩家可下注，赢家获得奖池扣除官方抽水后的奖金（依赖 EconomyAPI）

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 服务端 | Nukkit-MOT |
| Java | 17+ |
| 经济插件 | **EconomyAPI（强依赖）** |

> 本插件在 `plugin.yml` 中以 `depend: [EconomyAPI]` 声明强依赖。未安装 EconomyAPI 时，Nukkit 会直接拒绝加载本插件，不会以「赌博不可用」的降级形态运行。

## 安装

1. 构建或下载 `TabletopGame-1.0.0-SNAPSHOT.jar`
2. 将 jar 放入服务器 `plugins/` 目录
3. 确保已安装 `EconomyAPI`
4. 重启服务器

## 玩法说明

### 获取与放置棋盘

OP 使用命令获得棋盘物品后，手持对准地面右键放置：

- 放置需要对应的空地（五子棋 2×2 / 3×3，象棋与奥赛罗 2×2），空间不足或与已有棋盘重叠时会提示
- 棋盘朝向由放置时的视角决定，取最近的 90°：**0=南、1=西、2=北、3=东**；区域从放置点沿玩家左手边与正前方延伸
- 生存模式放置消耗 1 个物品，创造模式不消耗；棋盘物品堆叠上限为 1

### 打开菜单与入座

右键已放置的棋盘打开菜单。三种棋的菜单结构一致，内容随座位状态动态变化：

- **0 人入座**：选择棋色；三个等级的单人对战；更改设置（五子棋为「更改规则」）、赌博开关、关于规则
- **1 人入座**：其他人可加入对方棋色；本人可选单人对战或退出
- **2 人入座**：先加入者可选开始棋局，双方均可退出

> 「0 人入座」的菜单是**独占**的：同一时间仅一人可操作，避免两人同时抢座位或改设置。占用者超时（`menuLockSeconds`，默认 30 秒）或下线时会自动释放；点击「关于规则」会立即释放占用。

### 开始棋局

- 两名玩家入座后，由先加入者点击「开始棋局」
- 上一局已分出胜负/平局后不再提供「继承残局」，避免重复获胜与重复领奖
- 三人棋均支持「继承残局/继承棋局」：保留盘面与轮次继续对局

### 退出与收回棋盘

- 菜单点「退出棋局」
- 或离开棋盘中心一定范围（默认 7 格，可配置）自动退出
- 玩家下线自动离座
- 对局中有人退出会**中止本局并保留盘面**，可稍后「继承残局」继续
- 破坏棋盘任意一块方块即整体收回，并在原地掉落棋盘物品（需自行拾取；创造模式不掉落）。棋盘方块硬度与橡木板一致，斧头挖掘加速

---

### 五子棋

**棋盘与规则**

- 15×15 交叉点，**黑棋先手**，一人一手
- 在「0 人入座」菜单点击「更改规则」切换，仅 0 人入座且未开局时可改

**休闲模式**

- 标准五子棋，黑先白后，一人一手
- 任意方向连成 5 子即胜；长连（6 子及以上）同样算胜
- 开局后若盘面已有棋子且未分胜负，可点「开始棋局（继承棋局）」继续上一盘

**Swap2**

- 「假先手」在盘面任意位置摆 3 子，顺序为黑 → 白 → 黑
- 「假后手」三选一：继续执白 / 交换执黑 / 再落 2 子（先白后黑）
- 若选择再落 2 子，则由「假先手」二选一：继续执黑 / 交换执白
- 开局结束后回归一人一手，由白方落下一子
- 长连（6 子及以上）对双方都不算胜，对局继续
- 角色与选色：选黑者 = 假先手（摆 3 子），选白者 = 假后手（做选择）
- Swap2 开局规则较复杂，**不提供继承棋局**

---

### 中国象棋 [Beta]

**棋盘与开局**

- 9 列 × 10 行（90 个交叉点），32 枚棋子，**红方先手**，一人一手
- 点击交叉点行棋：先点己方棋子选中，再点落点走子；点己方另一子可改选，点回自身则取消选择

**各子走法**

- 车：横竖直线行走，路径上不得有子
- 马：走「日」字，蹩腿方向有子则不能走
- 象：走「田」字，塞眼有子则不能走，且不可过河
- 士：九宫内斜走一步
- 将/帅：九宫内直走一步
- 炮：不吃子时走法同车，吃子须隔且仅隔一枚棋子
- 兵/卒：过河前只可直走一步，过河后可横走一步，但不可后退

**将军与胜负**

- 被将军时必须应将，不可自将（走后己方仍被将军），将帅不可照面
- 走子受将军限制时提示「无法移动，我方被将军了！」
- 将死或困毙对方即获胜
- 和棋：同一局面三次重复，或连续 50 回合无吃子

**标记**

- 选中棋子显示实线框，对方回合期间常驻显示上一手走子的虚线框
- 双方各自一个准星高亮框

**音效**

- 走子、吃子、将军分别播放对应音效；走子结果为吃子且将军时只播放将军音效

---

### 奥赛罗（黑白棋）

**棋盘与开局**

- 8×8 共 64 格，**黑方先手**；开局中央已摆好 2×2 共 4 子（对角同色）
- 一人一手交替落子，**只能在能夹住对方棋子的空位落子**

**落子与翻转**

- 落子后，被夹住的对方棋子（横、竖、斜任一方向）翻成己方颜色
- 落子后等待 0.5 秒再一次性翻转所有需翻转的棋子，然后移交回合

**跳过与胜负**

- 一方无合法落点时自动跳过回合
- 双方均无合法落点（或棋盘下满）时对局结束，子多者胜，相等为和

**标记**

- 绿色标记提示当前行动方可落子的位置（常驻显示，不随玩家离开消失）
- 红色标记标出上一手落点
- 黄色方环跟随准星，帮助玩家定位当前所选格

**音效**

- 落子与翻转分别播放对应音效

---

### 单人对战

三种棋的菜单中均有「单人对战（入门 / 进阶 / 大师）」：

- 点击后玩家立即占座（对其他人视为满员），随后选择棋色（含「随机选择」），机器人自动坐到对面
- 机器人落子在**异步线程**计算，不阻塞服务器主线程
- 五子棋人机对战同样支持 Swap2；象棋为红先黑后；奥赛罗为黑先手

各档思考时间（单步上限 / 最短思考时间）：

| 棋种 | 入门 | 进阶 | 大师 | 引擎 |
| --- | --- | --- | --- | --- |
| 五子棋 | 即时 | 即时 | 迭代加深 α-β，最大深度 5，上限 1 秒 | 自研 |
| 中国象棋 | 3 层 | 6 层 | 9 层 | xqwlight（上限 4 秒 / 下限 1 秒） |
| 奥赛罗 | 2 层 | 4 层 | 6 层 | 自研（上限 2.5 秒 / 下限 1 秒） |

### 赌博模式

仅在**玩家对玩家**对局中生效，由先落座玩家在「0 人入座」菜单开启，三种棋通用：

- 开启后隐藏单人对战入口（二者互斥）
- 开局时输入下注金额（需在 `minBet` ~ `maxBet` 之间），双方各扣除该金额，奖池为下注额 × 2
- 获胜方获得「奖池 − 官方抽水」的奖金；平局全额退还
- 中途有玩家退出时，判仍在座的一方获胜并正常结算（不退注）
- 依赖 EconomyAPI，余额不足或扣款失败会给出提示

## 配置文件

首次启动会在 `plugins/TabletopGame/config.yml` 生成配置（三种棋共用）：

```yaml
# 玩家离开棋盘中心多少格后自动退出棋局（水平方向）
playerRange: 7.0

# 0 人入座时菜单的独占超时（秒）。超时或持有者下线会自动释放占用
menuLockSeconds: 30

# 赌博模式设置（仅玩家对玩家对局生效；本插件强依赖 EconomyAPI）
gambling:
  # 官方每局抽水百分比（0~100，保留两位小数）。默认 1.0 即 1%
  cut: 1.0
  # 每局可下注的最小金额
  minBet: 1000.0
  # 每局可下注的最大金额
  maxBet: 1000000.0
```

说明：

- 修改后执行 `/tabletopgame reload`（OP 或控制台）热重载
- **已生成的 `config.yml` 不会被重载改写**：新增配置项后需手动删除文件重建，或手动补齐字段

## 数据存储

三种棋各用独立存档文件，均位于 `plugins/TabletopGame/`，每行一条记录，用 `|` 分隔：

**五子棋 `boards.txt`**

| 行 | 内容 |
| --- | --- |
| `B` | 棋盘头部：世界、坐标、朝向、是否进行中、回合、胜者、机器人等级/棋色、棋盘边长、下注金额、赌博开关、规则、Swap2 阶段/已摆子数 |
| `S` | 座位：玩家 UUID + 棋色 |
| `N` | 玩家名缓存：UUID + 名字（离线时用于显示） |
| `R` | 15 行落子状态的三进制编码 |

**中国象棋 `xiangqi_boards.txt`**

- 格式：`X|世界|X|Y|Z|朝向|turn|started|grid`
- `turn` ∈ {0(红),1(黑)}；`started` ∈ {0,1}
- `grid` 为 90 字符，第 `row*9+col` 位：`.` = 空，其余为贴图编号的小写十六进制单字符

**奥赛罗 `othello_boards.txt`**

- 格式：`O|世界|X|Y|Z|朝向|turn|started|grid`
- `turn` ∈ {1(黑),2(白)}；`started` ∈ {0,1}
- `grid` 为 64 字符，第 `row*8+col` 位：`.` = 空，`1` 黑 / `2` 白

启动时由 tick 在关卡加载完成后异步解析并回主线程重建棋盘与棋子实体；保存采用「主线程生成快照 + 单线程异步写盘」，且只重建状态发生变化的棋盘的快照。

## 构建

需要 JDK 17 与 Maven：

```bash
mvn clean package
```

产物：`target/TabletopGame-1.0.0-SNAPSHOT.jar`

## 性能说明

- 机器人搜索、配置解析、存档写盘、读档解析均在异步线程执行，主线程只做状态读取与快照生成
- 每种棋按关卡索引棋盘，tick 时跳过无人在线的关卡，准星/范围检测只处理玩家所在关卡
- 落子状态批量同步（一次发包），棋子计数与判满为 O(1)
- 同一 tick 内每人只计算一次高亮；范围比较使用平方距离
- 象棋 32 子、奥赛罗 64 格均由**单个实体**渲染，避免大量实体同步与更新开销
- 存档只重建「变脏」棋盘的快照，玩家识别半径等高频配置项以基本类型字段缓存
